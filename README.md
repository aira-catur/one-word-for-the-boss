A deterministic Python program (standard library only, no network) that writes
exactly one word describing the boss — no spaces, no newline — to `entry.txt`
in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The word: **Gloryhound** — the boss who hunts down the glory for the team's
work. It stands alone, it rings true in a kitchen, a warehouse or an office,
and it is not the first word anyone reaches for.
